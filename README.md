# All or Nothing

## Game promotion

The non-Steam title menu includes a dismissible Steam-edition card. Extra → More from DeeGee Games opens the game shelf on every platform; Steam players are offered the free web release instead. The card has a single destination and no rotation controls.

The bundled catalog lives in `src/promotions/catalog.ts`. Add Math Marsh when its store listing is ready. Steam uploads receive a `steam_appid.txt` marker after standalone packaging, so release detection remains independent of Steam initialization and the standalone installers keep their promotion.
